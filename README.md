# 서울시 젠트리피케이션 영향요인 분석 및 단계 예측

> 서울시 상권 데이터 기반 젠트리피케이션 패턴 분석 및 AI 예측 모델 연구

## 프로젝트 개요

본 연구는 서울시 상권의 다차원 사회경제적 데이터를 활용하여 젠트리피케이션 패턴을 분석하고 예측합니다. 국토교통부의 젠트리피케이션 진단체계를 기반으로 상권을 4단계로 분류하고, 머신러닝 및 딥러닝 기법을 활용하여 미래 젠트리피케이션 위험 지역을 예측합니다.

### 연구 목표

- 상권 데이터 기반 젠트리피케이션 패턴 탐지
- 사회경제적 변화 초기 징후를 보이는 지역 군집 식별
- 데이터 기반 미래 젠트리피케이션 위험도 예측 모델 개발
- 도시 정책 수립을 위한 실질적 인사이트 제공

## 젠트리피케이션 진단 프레임워크

국토교통부 진단체계에 따라 4단계로 분류:

| 단계 | 명칭 | 특징 |
|------|------|------|
| **0단계** | 초기 | 젠트리피케이션 미발생 또는 재쇠퇴 상태 |
| **1단계** | 주의 | 낮은 임대료, 정책 지원으로 자본 유입 시작 |
| **2단계** | 경계 | 임대료 급상승, 지역 명소화, 업종 변화 빈번 |
| **3단계** | 위험 | 과잉 산업화, 비자발적 이주, 상권 쇠퇴 가능성 높음 |

## 분석 기법 및 모델

### 1단계: K-Means 군집분석

**방법론**
- Elbow Method로 최적 군집 수 결정 (K=4)
- Silhouette Score 검증: 0.3
- PCA 시각화로 군집 분포 확인

**군집 분류 결과**
- 군집 0 (경계 단계): 2,098개 상권 - 집객시설, 생활인구, 지출 최고
- 군집 1 (초기 단계): 1,120개 상권 - 인프라 낮지만 영업기간 최장
- 군집 2 (위험 단계): 913개 상권 - 아파트 가격/지출 높고 인구 감소
- 군집 3 (주의 단계): 732개 상권 - 시설/인구 많지만 아파트 단지 적음

### 2단계: 머신러닝 모델

#### Logistic Regression
- 정확도: 59.2%
- ROC-AUC: 대부분 클래스에서 0.9 미만
- 결론: 다중 클래스 분류에 부적합

#### PyCaret 기반 모델 선정

| 모델 | RMSE |
|------|------|
| **Extra Trees Regressor** | **0.0364** |
| **Random Forest Regressor** | **0.0372** |
| Light Gradient Boosting | 0.0504 |
| Decision Tree Regressor | 0.0456 |

**특성 중요도 분석 결과**

*Extra Trees Regressor 주요 특성*
1. 전통시장 (상권 R): 0.2777
2. 발달상권 (상권 D): 0.1717
3. 교육 지출: 0.0543
4. 의료비 지출: 0.0505
5. 총지출액: 0.0485

*Random Forest Regressor 주요 특성*
1. 전통시장 (상권 R): 0.3058
2. 발달상권 (상권 D): 0.1854
3. 교육 지출: 0.1745
4. 남성 생활인구: 0.0889
5. 의류 지출: 0.0558

### 3단계: Transformer 딥러닝 모델

**모델 아키텍처**
- Transformer 레이어: 2개
- Attention 헤드: 4개
- 배치 크기: 64
- 에포크: 1000 (조기 종료: 50 에포크)
- 옵티마이저: Adam
- 손실 함수: Categorical Cross-Entropy with Softmax

**성능 지표**
- **검증 손실**: 0.0092
- **정확도**: 99%
- **RMSE**: 0.0641

**Attention 가중치 분석**

긍정적 영향 (높은 가중치):
- 10대 생활인구: 0.8325
- 집객시설 수: 0.7688
- 폐업 영업 기간: 0.6877
- 20대 생활인구: 0.4971
- 버스정류장 수: 0.4380

부정적 영향 (낮은 가중치):
- 대학교 수: -0.8070
- 화요일 생활인구: -0.8006
- 40대 생활인구: -0.5029
- 시간대 6 (20-24시) 인구: -0.4754

## 2023년 예측 결과

학습된 Transformer 모델을 2023년 1분기 데이터 (342개 상권)에 적용:

| 단계 | 상권 수 | 비율 |
|------|---------|------|
| 0단계 (경계) | 14개 | 4.1% |

| 2단계 (위험) | 6개 | 1.8% |
| 3단계 (주의) | 146개 | 42.7% |

**고위험 상권 (2단계 - 위험)**
- 오목교역
- 구로디지털단지
- 강남을지병원
- 언주역 (차병원)
- 청담사거리 (청담명품거리)
- 개롱역
