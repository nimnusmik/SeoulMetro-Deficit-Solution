# 서울시 지하철 만성적자 해소 정책 제안

> 공공데이터 분석을 통한 지속가능한 교통복지 정책 연구

## 프로젝트 개요

본 프로젝트는 서울시 지하철의 만성적인 재정난 문제를 데이터 기반으로 분석하고, 노인층·서울시·서울교통공사 모두가 수용 가능한 지속가능한 교통복지 정책을 제안합니다.

### 연구 배경

**서울시 지하철 재정 현황**
- 전년도 1조 원 이상의 만성적 적자 발생
- 2020년 기준 무임승차 손실액: 약 2,643억 원
- 7년째 동결된 지하철 요금 (2015년 이후)
- 증가하는 운영비용 vs 정체된 수입

**무임승차 현황**
- 2020년 무임승차 비율: 노인 81.8%, 장애인 17.1%, 국가유공자 1.1%
- 고령화 사회 진입으로 노인 무임승차 비중 지속 증가
- 2017-2019년 연평균 무임승차 손실액: 약 3,500억 원

## 분석 방법론

### 1단계: 변수 선정

**XGBoost 변수 중요도 분석**
- Gain 기반 변수 중요도 확인
- F-score 상위 16개 변수 선정

**다중선형회귀분석**
- 후진제거법 적용
- p-value 0.05 이상 변수 순차 제거

**상관계수 및 다중공선성 확인**
- Target(무임승하차) 상관계수 0.1 이상 변수 확인
- VIF(Variance Inflation Factor) 검증
- 모든 변수의 VIF < 10 달성

**최종 선정 변수 (12개)**
1. 2020 세금평균 (자동차세, 재산세, 지방소득세)
2. 노인인구수
3. 무임승하차
4. 무임승하차 비율
5. 유임승하차
6. 출퇴근시간 이용객수
7. 노인인구비율
8. 지역별 기초수급자 비율
9. 자치구별 재난지원금 대상자 비율
10. 250m내 버스정류장 수
11. 인구밀도 (명/㎢)
12. 평균연령

### 2단계: K-means Clustering

**군집 개수 결정**
- Silhouette Score를 이용한 최적 군집 수 선정
- 최적 군집 개수: **3개**

**군집 분포**
- 0번 군집: 174개 역 (58%)
- 1번 군집: 23개 역 (8%)
- 2번 군집: 101개 역 (34%)

**군집별 특성**

| 특성 | 0번 군집 | 1번 군집 | 2번 군집 |
|------|----------|----------|----------|
| **대표역** | 동대문, 동묘앞, 신설동, 제기동, 가락시장 | 서울역, 종각, 강남, 건대입구, 사당, 신도림 | 시청, 종로3가, 청량리, 구의, 낙성대, 당산 |
| **무임승하차 수** | 90,138명 | 29,986명 | 189,413명 |
| **무임승하차 비율** | 18.81% | 10.31% | 14.97% |
| **출퇴근 이용객수** | 160,225명 | 975,946명 | 415,165명 |
| **세금평균** | 173,319원 | 254,617원 | 191,311원 |

## 정책 제안

### 효율적 방안 모색 3가지 관점

```
        노인층
       /   |   \
      /    |    \
무임승하차  혼잡도  소득분위
     \    |    /
      \   |   /
    지속가능한 교통복지
```

### 1안: 출퇴근 시간대 무임승차 혜택 제한

**배경**
- 평일 출퇴근 시간대 혼잡도 심각
- 오전 7-10시, 오후 5-8시 집중

**정책 내용**
- 평일 오전 7-10시, 오후 5-8시 무임승차 혜택 제한
- 해당 시간대 모든 탑승 인원 1,250원 요금 지불

**기대효과**
- 21년 7월~22년 5월 전체 노인 승하차수: 324,372,125명
- 평일 출퇴근시간대 노인 승하차수: 82,110,650명
- **25%의 승객이 요금 지불** → 약 1,026억 원 수입 증가

### 2안: 군집당 소득분위별 가격 차등화

**배경**
- 2020년 5분위별 가구 소득 격차 존재
- 지역별 경제 수준 차이 반영 필요

**정책 내용**

| 분위 | 0번 군집 | 1번 군집 | 2번 군집 | 개인 소득 (만원) |
|------|----------|----------|----------|-----------------|
| 1분위 | 90원 | 280원 | 180원 | 493.7 |
| 2분위 | 140원 | 450원 | 290원 | 801.5 |
| 3분위 | 220원 | 720원 | 460원 | 1,272.5 |
| 4분위 | 320원 | 1,020원 | 650원 | 1,807.8 |
| 5분위 | 390원 | 1,250원 | 790원 | 3,413.3 |

**기대효과**
- 0번 군집: 0.1856% 복구 (약 25억 원)
- 1번 군집: 0.5952% 복구 (약 34억 원)
- 2번 군집: 0.3792% 복구 (약 60억 원)
- **총 34% 재정난 완화** (약 119억 원)

### 3안: 1안 + 2안 혼합 정책

**정책 내용**
- 출퇴근 시간대 제한 + 소득분위별 차등화 동시 적용

**기대효과**

| 구분 | 무임비용 | 복구액 | 복구 비율 |
|------|----------|--------|-----------|
| 0번 군집 | 132.95억 원 | 24.68억 원 | 18.56% |
| 1번 군집 | 57.06억 원 | 33.96억 원 | 59.52% |
| 2번 군집 | 158.87억 원 | 60.24억 원 | 37.92% |
| **전체** | **348.88억 원** | **118.88억 원** | **34.07%** |

**종합 복구율**
- 1안 단독: 25% 완화
- 2안 단독: 34% 완화  
- **혼합 정책: 50% 완화 가능**

## 프로젝트 의의

### 정책이 가지는 의의

**균형적 접근**
- 무임수송은 지하철 재정난의 대표적 원인이지만, 노인의 무임혜택만을 탓하는 것은 부당
- 지하철 역, 소득분위, 시간대 등 다양한 관점에서 각 특성을 반영

**이해관계자 고려**
```
    노인층
   /      \
  /        \
서울시 ← → 서울교통공사
```

- 노인층: 빼앗길 위기 속 복지 혜택 유지 필요
- 서울시(정부): 공익서비스 제공 책임
- 서울교통공사: 매 순간 불어나는 적자 해결 필요

**지속가능한 교통복지**
- 세 입장 모두를 아우를 수 있는 정책 연구
- 양측의 입장을 고려한 균형적 해결방안 제시
